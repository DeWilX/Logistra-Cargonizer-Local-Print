LOGISTRA PRINT — WINDOWS

GETTING STARTED

1. Move Logistra-Print.exe to a permanent, writable folder and open it.
   Python is included; no separate installation is required.
2. In Settings, enter your own Cargonizer Sender ID and API key.
   Click Save and check. Leaving the key field blank keeps the existing key.
3. In Printer and PDF, select an installed printer and save it.
   Test print uses the included 102 x 192 mm test label.
   When printing through Adobe, use Actual size / 100% and one copy.
4. Shipments load on launch when an API key is saved.
   Select a period preset or dates in the calendar. After entering dates
   manually, click Filter. Use Ctrl/Shift to select multiple shipments.
5. On Home, search by shipment ID or the complete reference / order number.
   PDF filenames include the ID and reference. Open PDF folder opens the
   configured download folder.
6. Enable automation separately. On its first run, existing shipments are
   recorded as a baseline. Uncertain print results are not retried automatically.

Microsoft Print to PDF saves a copy of the original PDF in your chosen folder.
It does not test a physical printer. Acceptance of a print command does not
confirm physical printing. Check the printer queue before reprinting.

SETTINGS AND STATUS

Settings lets you choose the PDF folder, System/Light/Dark appearance and
Latvian, English or Norwegian Bokmal. Language changes apply immediately.
The minimum polling interval is 5 seconds. API rate-limit errors trigger a pause.
Dismiss setup only hides the initial setup panel; it does not mark checks passed.
Green/red indicators show actual check results. Hover for an explanation.
A saved printer that is unavailable is shown as not configured.
A successful empty shipment list is normal.

SYSTEM TRAY AND WINDOWS STARTUP

The tray icon remains available while the application is running.
Close to system tray controls what the window's X button does. To exit
completely, select Exit from the tray menu. A second instance cannot run.
Windows startup creates a Logistra Print shortcut with an icon and a hidden
window. After moving the EXE, save the startup setting again.

UPDATES

The update source is included in the build; no repository entry is required.
Check for updates finds the latest public GitHub Release. Download and update
verifies the EXE's size and SHA-256 digest, waits for active work to finish,
keeps a backup of the previous EXE and restarts the application.
The EXE folder must be writable. Diagnostics are stored at:
%LOCALAPPDATA%\Logistra\updates\update.log

Version 0.1.8 fixes restarting the packaged EXE after replacement. If an older
version closes without restarting during an update, download the latest EXE,
close any remaining Logistra instance and replace the old EXE manually once.
Future updates use the corrected updater. Settings and print history remain.

USER DATA

The account settings, API key and print history are stored in:
%LOCALAPPDATA%\Logistra

Updates preserve these files. The API key is protected with Windows DPAPI
and belongs to the Windows user and computer where it was saved.
The EXE is currently not signed with a publisher certificate.
